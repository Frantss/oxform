# API Reference

The Solid adapter preserves the core validation, issue, submission, reset, and array contracts. Its primitives add owner cleanup, reactive getters, and dynamic bindings. Call them inside a component or `createRoot`.

These contracts apply to both `oxform-solid` for Solid 1 and `oxform-solid/v2` for Solid 2. Examples and generated type tables use the Solid 1 entry. With Solid 2, import Oxform primitives, components, and types from `oxform-solid/v2`; use `@solidjs/web` for web rendering and JSX types. See the [Solid 2 guide](/docs/solid/guide/solid-2) for setup and reactive timing.
