# Oxform Solid

Try the [Solid playground](/playground?framework=solid&example=account) for an
interactive account form with source viewing.

`@oxform/solid` connects the core form API to Solid's reactivity. Create a form inside a component, connect fields to controls, and read reactive getters in JSX.

Both adapters ship in one package. Choose the entry matching your application's Solid version:

| Solid version | Import             | Setup                                                  |
| ------------- | ------------------ | ------------------------------------------------------ |
| `^1.9.0`      | `@oxform/solid`    | Install below.                                         |
| `2.0.0-rc.13` | `@oxform/solid/v2` | Follow the [Solid 2 guide](/docs/solid/guide/solid-2). |

## Install

For Solid 1, install Solid `^1.9.0` and a Standard Schema validator, such as Zod. The examples on the shared API pages use this entry.

```bash
pnpm add @oxform/solid solid-js@^1.9.0 zod
```

## First Form

```tsx twoslash
// @jsx: preserve
// @jsxImportSource: solid-js
import { createField, createForm } from '@oxform/solid';
import { For } from 'solid-js';
import { z } from 'zod';

const schema = z.object({ email: z.email() });

export function Signup() {
  const form = createForm({
    schema,
    defaultValues: { email: '' },
    checks: { error: { validate: { change: schema } } },
  });
  const email = createField({ form, name: 'email' });
  const submit = form.submit(values => {
    console.info(values.email);
  });

  return (
    <form
      onSubmit={event => {
        event.preventDefault();
        void submit();
      }}
    >
      <label for='signup-email'>Email</label>
      <input id='signup-email' type='email' {...email.props} />
      <For each={email.state.issues.error}>{entry => <p>{entry.issue.message}</p>}</For>
      <button type='submit' disabled={form.status.submitting}>
        Sign up
      </button>
      <button type='button' onClick={() => form.reset()}>
        Reset
      </button>
    </form>
  );
}
```

The schema infers values and field paths. Input props use `onInput` to write text during typing. Configured change validation updates `email.state.issues`; `form.submit` validates again before calling the success callback.

## Choose an API

| Task                         | API                                 |
| ---------------------------- | ----------------------------------- |
| Create a form                | `createForm`                        |
| Connect a control            | `createField` or `Field`            |
| Use imperative field methods | `createFieldApi`                    |
| Manage a dynamic list        | `createArrayField` or `ArrayField`  |
| Observe a selected value     | `createSubscribe` or `Subscribe`    |
| Read aggregate form status   | `form.status` or `createFormStatus` |
| Run a callback on changes    | `createFormEffect`                  |

## Runnable Example

The repository's `examples/solid` workspace includes validation feedback, checkbox handling, keyed array rows, subscriptions, effects, submission, and reset.

```bash
pnpm install
pnpm --dir examples/solid run dev
```

For Solid 2, run `pnpm --dir examples/solid-v2 run dev` instead.
