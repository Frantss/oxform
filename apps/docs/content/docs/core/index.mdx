## In short

`@oxform/core` makes forms and the pieces that a form is made of. A form is a chain of extensions on `defineForm`,
and `form.create` makes an instance of it. The built-in extensions are in `@oxform/core/behaviors`, and the
presets are in `@oxform/core/presets`.

## From form to instance [#form-to-instance]

Four lines take a schema to a live form: define the form, extend it, configure it, create an instance.

```ts twoslash
import { defineForm } from '@oxform/core';
import { check, validation, values } from '@oxform/core/behaviors';
import { z } from 'zod';

const schema = z.object({ email: z.email(), password: z.string().min(8) });

const signIn = defineForm({ schema, defaultValues: { email: '', password: '' } })
  .extend(values)
  .extend(validation)
  .extend(check('error', { blocking: true, exclusive: true }))
  .configure({ error: { submit: schema } });

const form = signIn.create();
```

The full sign-in chain of E01 also has `status`, `events`, `submit` and its slot groups. See
[`form.extend`](/docs/core/extend).
