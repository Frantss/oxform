## Problem

"Discard" must return to the last saved text, not to the first loaded text.

## Solution

Keep the last saved values. `reset.all({ values })` resets the form to the values that you give, and the status of
each field is clean again. After a save, call it with the saved values, so they are the new baseline. "Discard"
calls it with the baseline.

## How it works

- `reset.all()` with no values returns to the default values of the instance. With `values`, it starts from those
  values. The default values of the form do not change.
- A reset restores the field status and the form status and clears the entries of each check, so "Unsaved
  changes" goes away.

## Variations

- To discard one field, call `reset.at(path)`. It restores the value at the path from the default values, or from
  its `value` option, and clears the field status and the entries at the path.
