## Problem

A change of country makes the region invalid.

## Solution

Listen to the changes of the form with `values.onChange`. When the change is at `country` and the region is not
empty, set the region to `''`. The function returns the `Unsubscribe` of the listener.

<include meta='no-check="checked in the example kit"'>../../../../../examples/kit/src/region.ts</include>

The region select starts the listener in an effect and stops it when it leaves the tree. It reads the country with
`useSelector` to list the regions of that country.

## How it works

- `values.onChange` runs after each write, with the path of the change. The listener writes the region with
  `values.set`, which is a second change at `region`. That change does not match `country`, so the listener
  stops there.
- The listener reads the region before it writes, so a region that is already empty causes no write.

## Variations

- To change a value before it is written, such as to trim it, use `values.intercept` in an extension. See
  [Change a value before it is written](/docs/extend/intercept-a-change).
- To start the listener for every instance, write it in the `api` of an extension instead of a component.
