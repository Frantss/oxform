## In short

A recipe solves one common task with the forms of the example kit. Each one shows the framework-neutral code of
the kit and its React rendering.

## The recipes [#the-recipes]

| Recipe                                                             | Task                                                              |
| ------------------------------------------------------------------ | ----------------------------------------------------------------- |
| [Validate on the server on blur](/docs/recipes/lookup-on-blur)     | Look up a value on the server when the user leaves the field      |
| [Errors from the server](/docs/recipes/server-errors)              | Show one error from `onSubmit`, or a list of errors by path       |
| [Dependent fields](/docs/recipes/dependent-fields)                 | Clear one field when another field changes                        |
| [Unsaved changes](/docs/recipes/unsaved-changes)                   | Show a label, disable a button, and warn before the tab closes    |
| [Discard changes](/docs/recipes/discard-changes)                   | Return to the last saved values                                   |
| [Third-party controls](/docs/recipes/third-party-controls)         | Connect a control that reports a value and no DOM event           |
| [A part with another element](/docs/recipes/another-element)       | Render a slot in a `select`                                       |
| [Read one value](/docs/recipes/derived-ui)                         | Update a summary when one value changes                           |
| [A form without JavaScript](/docs/recipes/form-without-javascript) | Validate a posted form in a request handler and render its errors |
