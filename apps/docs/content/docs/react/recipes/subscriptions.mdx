# Subscriptions

Use `Subscribe` to render a selected value without wiring the whole form state through a parent component.

```tsx twoslash
import { Subscribe, useForm } from '@oxform/react';
import { z } from 'zod';

const schema = z.object({
  email: z.string(),
});

function ValidationStatus() {
  const form = useForm({ schema, defaultValues: { email: '' } });

  return (
    <Subscribe api={form} selector={state => state.status.valid}>
      {valid => <span>{valid ? 'No blocking issues' : 'Needs attention'}</span>}
    </Subscribe>
  );
}
```
