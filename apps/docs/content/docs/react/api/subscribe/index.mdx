# Subscribe

`Subscribe` and `useSubscribe` accept a form, field, or array API and a selector over its store state. The selector's return type determines the selected value type. Selecting state does not change values, status, or validation.

## `useSubscribe(api, selector)`

Returns the current selected value and subscribes the component to selected state changes. Form selectors receive `FormStore`; field and array selectors receive their respective stores.

```tsx twoslash
import { useFieldApi, useForm, useSubscribe } from '@oxform/react';
import { z } from 'zod';

function EmailPreview() {
  const form = useForm({ schema: z.object({ email: z.string() }), defaultValues: { email: '' } });
  const email = useFieldApi({ form, name: 'email' });
  const value = useSubscribe(email, state => state.value);
  const submitting = useSubscribe(form, state => state.status.submitting);

  return <span aria-busy={submitting}>{value}</span>;
}
```

## `Subscribe`

| Prop       | Behavior                                                        |
| ---------- | --------------------------------------------------------------- |
| `api`      | API whose store is observed.                                    |
| `selector` | Function returning the selected value from current state.       |
| `children` | Render function receiving that value, or static React children. |

The component subscribes through `useSubscribe` and adds no DOM wrapper.

```tsx twoslash
import { Subscribe, useForm } from '@oxform/react';
import { z } from 'zod';

function SubmitButton() {
  const form = useForm({ schema: z.object({ email: z.string() }), defaultValues: { email: '' } });

  return (
    <Subscribe api={form} selector={state => state.status.submitting}>
      {submitting => (
        <button type='submit' disabled={submitting}>
          Submit
        </button>
      )}
    </Subscribe>
  );
}
```

Use [useFormEffect](/docs/react/api/effects) for a callback when selected state changes, or [useFormStatus](/docs/react/api/status) for all form status properties.
