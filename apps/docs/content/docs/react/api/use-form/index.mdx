# useForm

`useForm` creates the form API that fields, array fields, subscriptions, and submit handlers use.

```tsx twoslash
import { useForm } from 'oxform-react';
import { z } from 'zod';

const schema = z.object({
  email: z.string(),
});

const form = useForm({
  schema,
  defaultValues: {
    email: '',
  },
});

form.store.state.values.email;
//                      ^?
```
