# Oxform React

`@oxform/react` provides React hooks and render-prop components over `@oxform/core`.

It is designed around a small set of primitives:

- `useForm` creates the form API.
- `Field` and `useField` connect individual fields to UI controls.
- `ArrayField` and `useArrayField` manage dynamic list fields.
- `Subscribe` and `useSubscribe` read selected form state.

## Install

```bash
pnpm add @oxform/react zod
```

```bash
npm install @oxform/react zod
```

## First form

```tsx twoslash
import { Field, Subscribe, useForm } from '@oxform/react';
import { z } from 'zod';

const schema = z.object({
  email: z.email(),
  password: z.string().min(8),
});

export function LoginForm() {
  const form = useForm({
    schema,
    defaultValues: {
      email: '',
      password: '',
    },
  });

  return (
    <form
      onSubmit={event => {
        event.preventDefault();
        void form.submit(values => {
          console.info(values.email);
        })();
      }}
    >
      <Field form={form} name='email'>
        {field => <input type='email' {...field.props} />}
      </Field>

      <Field form={form} name='password'>
        {field => <input type='password' {...field.props} />}
      </Field>

      <Subscribe api={form} selector={state => state.status.submitting}>
        {submitting => <button disabled={submitting}>Sign in</button>}
      </Subscribe>
    </form>
  );
}
```

`form.submit(onSuccess, onError?)` returns an async function. Invoke that
function after preventing the browser's default submit behavior. Submit
validation uses the root schema unless an error-level submit check is configured.
